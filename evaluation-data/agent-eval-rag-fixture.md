## Spring 依赖注入

依赖注入（Dependency Injection，DI）把对象依赖的创建和装配交给容器管理。Spring 容器根据 Bean 定义完成实例化，并优先通过构造器把依赖传入业务对象。构造器注入能明确表达必需依赖，也更方便编写单元测试；业务类不需要主动调用 `new` 查找具体实现，从而降低耦合。

## Redis 缓存失效策略

JMindOps 的缓存失效采用多层策略：对短期查询结果设置 TTL，防止陈旧数据永久驻留；写路径成功后主动删除对应缓存键；热点键加入随机过期抖动，减少同一时刻集中失效；缓存未命中时通过互斥或 single-flight 合并并发回源。对于删除失败等异常情况记录日志并依赖较短 TTL 最终收敛，不宣称缓存与数据库之间具备分布式事务。

## RRF 计算方式

Reciprocal Rank Fusion（RRF）不直接相加不同检索器的原始分数，而是只使用候选文档在每一路结果中的排名。JMindOps 使用：

`RRF(d) = Σ 1 / (60 + rank_i(d))`

其中常数 `60` 用于平滑头部排名差异。一个 chunk 同时在 BM25 和向量召回中排名靠前时，会得到更高的融合分数。
